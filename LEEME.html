Guía paso a paso

Publicar Socio Café como aplicación

Al terminar vas a tener una dirección propia (por ejemplo tuusuario.github.io/socio-cafe) que se instala como aplicación en el celular y en la computadora. Los socios y las cafeterías la usan sin cuenta de Claude. Todo es gratis.

Qué hay en esta carpeta

index.htmlLa aplicación.
config.jsLos datos de conexión a tu base de datos. Lo completás en el paso 1.
manifest.webmanifestNombre, colores e ícono para instalarla.
sw.jsPermite instalarla y que abra rápido.
icons/Los íconos de la taza.
firestore.rulesLas reglas de seguridad de la base de datos. Las pegás en el paso 1.

Paso 1: crear la base de datos (Firebase)

  1. Entrá a console.firebase.google.com con tu cuenta de Google y tocá Crear un proyecto. Nombre: socio-cafe. Podés desactivar Google Analytics.
  2. En el menú de la izquierda: Compilación → Authentication → Comenzar. En Método de acceso elegí Correo electrónico/contraseña, activalo y guardá.
  3. Menú: Compilación → Firestore Database → Crear base de datos. Ubicación: southamerica-east1 (São Paulo). Elegí modo de producción.
  4. En Firestore, pestaña Reglas: borrá lo que hay, abrí el archivo firestore.rules con el Bloc de notas, copiá todo, pegalo y tocá Publicar.
  5. Tocá el engranaje → Configuración del proyecto. Abajo, en Tus apps, tocá el ícono </> (Web). Apodo: socio-cafe. No marques Hosting. Tocá Registrar app.
  6. Firebase te muestra un bloque con apiKey, authDomain, projectId, etc. Abrí config.js con el Bloc de notas y reemplazá cada PEGAR_AQUI por el valor correspondiente, entre comillas. Guardá.
Los datos de config.js no son secretos: Firebase los diseña para estar en la página. Lo que protege a tus socios son las reglas del punto 4.

Paso 2: subir la aplicación a GitHub

  1. Entrá a github.com y creá una cuenta si no tenés. El nombre de usuario va a ser parte de la dirección.
  2. Arriba a la derecha: + → New repository. Nombre: socio-cafe. Marcá Public. Tocá Create repository.
  3. En la página del repositorio tocá uploading an existing file. Arrastrá todos los archivos de esta carpeta y la carpeta icons (podés dejar afuera este LEEME). Abajo tocá Commit changes.
  4. Andá a Settings → Pages. En Source elegí Deploy from a branch, rama main, carpeta / (root), y Save.
  5. Esperá uno o dos minutos y recargá esa página: arriba aparece la dirección, del tipo https://tuusuario.github.io/socio-cafe/.

Paso 3: autorizar la dirección en Firebase

  1. En Firebase: Authentication → Configuración → Dominios autorizados → Agregar dominio.
  2. Escribí tuusuario.github.io (sin https ni /socio-cafe) y agregalo.

Paso 4: instalarla

  1. Android (Chrome): abrí la dirección → menú ⋮ → Instalar aplicación.
  2. iPhone (Safari): abrí la dirección → botón Compartir → Agregar a pantalla de inicio.
  3. Computadora (Chrome o Edge): abrí la dirección → ícono de instalar en la barra de direcciones (una pantalla con flecha) → Instalar.

Paso 5: primer uso

  1. Tocá Soy cafetería → Crear cuenta nueva y cargá tu cafetería con su usuario y contraseña.
  2. En Mi panel → Socios cargá a tus socios. Cada uno recibe su número.
  3. El socio abre la aplicación, escribe su número en Ver mi tarjeta y ve su consumo.
  4. Para sumar empleados: Mi panel → Mi cuenta → Agregar usuario.
Esta es una base de datos nueva: las cafeterías y los socios que cargaste en la versión de Claude (PHATTO, Nini Phatto y sus socios) no pasan solos. Hay que volver a cargarlos acá. Los socios reciben números nuevos.

Para actualizar la aplicación más adelante

En GitHub, entrá al repositorio, tocá Add file → Upload files, arrastrá el archivo nuevo (por ejemplo index.html) y Commit changes. En unos minutos la aplicación instalada se actualiza sola.
